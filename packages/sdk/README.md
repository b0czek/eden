# @edenapp/sdk

Eden supplies a desktop runtime for Electron products.
It manages app windows, sessions, permissions, settings, files, and app communication.

Start with the [Eden SDK handbook](https://github.com/b0czek/eden/blob/main/docs/README.md).

- [Create a consumer](https://github.com/b0czek/eden/blob/main/docs/consumer-development.md): install, configure, build, and run an Electron desktop.
- [Create an app](https://github.com/b0czek/eden/blob/main/docs/app-development.md): scaffold an app and package it for Eden.
- [Use the host API](https://github.com/b0czek/eden/blob/main/docs/main-process-api.md): execute trusted main-process work.
- [EdenCSS](edencss/README.md): use the injected app styles.
